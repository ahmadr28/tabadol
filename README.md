# Tabadol

Design preview for Tabadol (تبادل, "exchange"): a luxury rental marketplace that combines a subscription House Collection with Member Closets, where approved owners rent and sell their own pieces.

This is a static homepage mockup for review and feedback, not the production app. Prices, policies and copy marked with brackets (e.g. `$[PRICE]`) are placeholders.

## Files

- `index.html` – the homepage (HTML, CSS and a little JavaScript, no build step)
- `images/` – stock photos from Unsplash (free license), used as placeholders
- `brand/mark.svg` – the T mark (upside-down Arabic ت over a stem)
- `favicon.svg` – browser tab icon

## Viewing

Open `index.html` in a browser, or view the GitHub Pages site once Pages is enabled for this repo.
